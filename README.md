## Learning Path

A practical progression through this collection is:

1. Start with **Netdiscover on the Wire** for network discovery concepts.
2. Continue with **Nmap Port Sweep Mastery** for port and service enumeration.
3. Study **Enum with Precision** to reinforce systematic enumeration.
4. Explore **Rips Revealed** and **Rips and Repos** for reconnaissance and information discovery.
5. Move to **Dirb Hidden Paths** and **Dirbuster Depth Charge** for web-content enumeration.
6. Practice **Shared Files: Hidden Paths** for file and path discovery.
7. Study **Rips Webmin Recon Run** for Webmin-focused reconnaissance.
8. Explore **Subrion Slipstream** for web application security concepts.
9. Finish with **Rips to Root** for Linux root and privilege-escalation themes.
10. Use **Tech Supp0rt Triage** as an additional investigation-focused CTF exercise.

Adapt the sequence according to your existing Linux, networking, and web-security knowledge.

## How to Use the Labs

1. Select a lab from the index.
2. Open its direct Learn SecByte URL.
3. Review the lab objectives, prerequisites, and scope.
4. Work exclusively inside the authorized CTF or training environment.
5. Record discovered services, resources, technologies, and security observations.
6. Focus on understanding the security concept behind each challenge.
7. Consider how the relevant issue could be detected, prevented, or remediated.

For penetration testing learners, useful notes include reconnaissance methodology, discovered services, enumeration results, exposed resources, application technologies, and defensive controls.
